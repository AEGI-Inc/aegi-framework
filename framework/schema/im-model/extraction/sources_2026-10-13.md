## 공식 목록이 없는 것

| SaaS | 없는 것 | 문서에 있는 것 | 얻는 길 |
|---|---|---|---|
| Atlassian | 감사 action 기계 키 | 표시 이름 목록 | 조직 API `event-actions` (테넌트 필요) |
| Confluence | 제품 감사 이벤트 전체 | 「전체 목록 아님」으로 적힌 종류 | 조직 감사 활동 목록으로 대신 |
| Salesforce | SetupAuditTrail `Action` 값 목록 | 예시(`PermSetCreate`)만 | 테넌트 조회 |
| Salesforce | 사용자 권한(`PermissionsXxx`) 이름 목록 | 묶음 자리 `PermissionsPermissionName` 한 줄 | `PermissionSet` describe (테넌트 필요) |
| Google Workspace | 관리자 권한 기계 이름 (`privilegeName`) | 도움말의 표시 이름 | Directory API `privileges.list` (테넌트 필요) |

이 다섯은 공식 문서로 닫을 수 없다. 후보 추출 단계에서는 문서에 있는 표시 이름과 예시로 두고, 테넌트 연결 뒤 보탤지 정해야 한다.

## 다음

## 반영 (2026-10-14)

- Atlassian: 조직 관리 OpenAPI 4종은 provider `atlassian`으로, 감사 활동 목록은 범주별로 jira, confluence, atlassian에 나눠 넣었다(`normalize_atlassian.py`). Jira 감사 범주 표, OAuth scope 문서, Jira 기본 권한 키와 전역 권한, Confluence 공간 권한과 역할, 전역 권한도 옮겼다. Forge manifest와 Confluence 감사 도움말 문장 목록은 옮기지 않았다
- Salesforce: Platform Events 안내서(이벤트와 실시간 이벤트 모니터링 객체), EventLogFile 유형, Change Data Capture 머리 필드, Mobile SDK scope 표, REST 리소스를 옮겼다(`normalize_salesforce.py`). Metadata API 안내서는 아직 옮기지 않았다. scope HTML 두 개는 받을 때 오류 쪽(2,436바이트)이라 PDF 표를 썼다
- Slack 감사 문서판 46건과 관리자 역할 16개는 아직 보태지 않았다
