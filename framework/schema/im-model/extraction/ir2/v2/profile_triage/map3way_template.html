세 모델 오브젝트 대조

기존 오브젝트 목록(대시보드 v1, v2 시절), Cartography 노드, IM 오브젝트 모델 v1을 SaaS별로 한 줄씩 맞춘 표. 기준일 2026-10-19, IM 쪽은 v2 브랜치 결정 반영본.

결론

SaaS별 대조 수

기존aegi-schema AEGI_Object_List_Final_2026-09-20.xlsx의 최종 판정 「포함」 항목. 대시보드 v1, v2 데이터셋이 이 목록 ID(GH-v0.2, OKTA-v1, SLK-v5.1, GWS-v3)를 썼다. GitHub, Okta, Slack, Google Workspace 4개만 있다. Cartographycartography-cncf/cartography d994439(2026-10-16)의 노드 선언 70개와 그 수집 API. IM 수집IM v1 실행 Profile 75개(runtime-catalog.json). 실제 수집, 정규화하는 타입. IM 연구IM v1 연구 Object 타입 1,977개. 수집 Profile을 고르는 후보 카탈로그. 맞추는 법이름이 아니라 API로 잇는다. 기존 항목은 근거 API, Cartography는 수집 API를 원문 API의 ID 공간에 맞추고, 그 공간을 가진 IM 연구 타입과 수집 Profile로 이었다. 공간이 갈린 경우만 이름으로 합쳤고 행의 비고에 적었다.

행 수는 대조 행(같은 대상 하나) 단위다. 한 행에 기존 항목이나 Cartography 노드가 여럿 들어갈 수 있다. 「IM 연구에만」은 세 출처 중 어디에도 안 닿은 연구 타입 수다.
