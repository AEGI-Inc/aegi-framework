오브젝트 모델 규칙집

v1 1단계, 4단계와 v2 판단표 1~4차에서 사람이 정한 결정을 다시 쓸 수 있는 규칙으로 옮겼습니다. 새 SaaS를 더할 때 후보마다 규칙의 질문에 순서대로 답하고, 규칙이 정하지 못하거나 두 규칙이 부딪치는 것만 판단표에 올립니다.

  • 규칙 __RULES__개가 지난 판단 결정 __JUDG__건 중 __EXPL__건을 설명합니다. 결정마다 기록된 이유를 규칙에 대응시켰습니다. 규칙이 지난 결정과 어긋나지 않는다는 확인이고, 새 후보를 맞힌다는 증명은 아닙니다. 다음 단계로 넘긴 절차 결정 __PROCESS__건은 뺐습니다.
  • 사람 답 없이 정해지는 규칙은 __AUTO__개입니다. 관계 템플릿, 역할 칸, 부모 근거, 계약값, 비밀값 처리처럼 수집과 투영 코드가 이미 검사합니다. 일부만 자동인 규칙은 __PARTIAL__개입니다.
  • 제품 계열 표(S2)만으로 판단표 3차 223개 중 __E_OK__개를 맞혔고 __E_BAD__개가 부딪쳤습니다. 부딪친 것은 Codespaces 비밀값입니다. 제품 계열이면서 원문 스펙도 없어서, 규칙대로라면 판단표에 올라갑니다.
  • 나머지 __HUMAN__개는 질문에 답해야 정해집니다. 판단이 사라지지는 않지만, 매번 새로 따지던 일이 정해진 질문 몇 개에 답하는 일로 바뀝니다.

정할 것

  1. 이 규칙집을 v2 모델 판단의 기준으로 둘지
  2. 다음 SaaS(7단계 Salesforce, Jira, Confluence 실측)부터 판단표를 「규칙 적용 결과와 예외만」 보여 주는 방식으로 바꿀지
  3. 규칙 문구 중 고칠 것. 특히 S6(A, B를 가르는 기준)은 우선순위 판단이라 사람 몫으로 남겼습니다
